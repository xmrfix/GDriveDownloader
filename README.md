## ✨ Features

- ⚡ **Multi-Threaded Parallel Downloads**: Download up to 16 files simultaneously to saturate your full internet bandwidth.
- 📁 **Full Nested Folder Hierarchy**: Preserves recursive subfolders and files exactly as structured in Google Drive.
- 🛡️ **Bypass Google Drive Warning Screens**: Direct download streams bypassing quota & confirmation virus scan prompts.
- ⏸️ **Granular Queue Controls**: Start, Pause, Resume, Skip, Retry, and Cancel per-file or batch.
- 🔍 **File Extension Filtering**: Skip unwanted file types (`.txt`, `.log`, `.tmp`, `.nfo`, etc.) automatically.
- 🎨 **Modern Dark & Light Themes**: Sleek UI with 8 vibrant accent color presets.
- 🚀 **100% Standalone & Safe**: Self-contained Windows installer with clean uninstaller.
